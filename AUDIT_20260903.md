## 3. Risks / debt (prioritized)

**P0 — fix now:**
1. Interpreter mismatch (from `POSTMERGE_AUDIT_VERIFIED.md:7-11`): `privileged_installer.py:50-70` + `router.py:4989 PRIVILEGED_PYTHON=/usr/bin/python3` vs live sudoers `/opt/anaconda3/bin/python3`. Fresh install → silent elevation denial. Derive from `sys.executable`, test `rendered == running`.
2. Dirty tree + backup clutter: 5x `router.json.bak-*` in root, untracked audit docs. Risk: wrong config restored, secrets leak in backups. Move to `state/backups/`, gitignore, commit or stash `M` files.
3. Silent config fallback: `json.loads(read_text()) except (OSError,ValueError): pass` → defaults (`route_watcher.py:141,167,176,345`, `monitor.py:382-423`). Corrupt `router.json` → silently falls back to `127.0.0.1:2080`/direct. Must fail-closed with `ConfigError`.
